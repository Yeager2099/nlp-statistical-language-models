# Statistical Language Modeling and Name Classification

**Course:** CIS 5300 / HW3  
**Artifact type:** Course project / coursework

## Overview

Implemented character n-gram models with add-k smoothing, interpolation, generation, and perplexity computation. Applied country-specific language models to city-name classification.

## Guiding question

How do smoothing and interpolation affect character language modeling and city-name classification?

## Methods and technical scope

Python; n-grams; smoothing; interpolation; perplexity.

## Evaluation and analysis

Compare model settings using perplexity and classification performance, then inspect errors. Do not present this as neural language modeling.
